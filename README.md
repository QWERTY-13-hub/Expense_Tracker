## Описание программы

**Expense Tracker** — это графическое приложение для учёта личных расходов. Программа позволяет:

- Добавлять расходы с указанием суммы, категории и даты
- Просматривать все расходы в виде таблицы
- Фильтровать расходы по категории и по диапазону дат
- Подсчитывать сумму расходов за выбранный период
- Удалять ненужные записи
- Автоматически сохранять данные в JSON-файл
