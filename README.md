## Описание программы

**Expense Tracker** — это графическое приложение для учёта личных расходов. Программа помогает отслеживать, куда уходят деньги, анализировать траты по категориям и за выбранные периоды.

---

## Возможности программы

| Функция | Описание |
|---------|----------|
| ➕ Добавление расходов | Указание суммы, категории и даты |
| 📋 Просмотр всех расходов | Удобная таблица с ID, датой, категорией, суммой |
| 🔍 Фильтрация по категории | Показывает расходы только выбранной категории (Еда, Транспорт и т.д.) |
| 📅 Фильтрация по дате | Задаётся период «с» и «по» |
| 💰 Подсчёт суммы за период | Автоматический расчёт общей суммы за выбранный диапазон дат |
| 🗑 Удаление расходов | Удаление ненужных записей с подтверждением |
| 💾 Автосохранение | Все данные сохраняются в файл `expenses.json` |
| 🔄 Загрузка при запуске | При следующем открытии все расходы на месте |

---

## Требования для запуска

- **Python 3.8** или выше
- **Библиотека tkcalendar** (для календаря)

> **Важно:** `tkinter` входит в стандартную поставку Python, устанавливать отдельно не нужно.

## Примеры использования

### Пример 1: Добавление расхода на еду

1. В поле «Сумма» введите: `350.00`
2. В поле «Категория» выберите: `Еда`
3. В поле «Дата» выберите: `2026-05-04`
4. Нажмите кнопку «Добавить расход»

**Результат:** Появляется сообщение «Расход 350.00 руб добавлен!», в таблице отображается новая запись.

---

### Пример 2: Фильтрация расходов на транспорт за неделю

**Задача:** Узнать, сколько потрачено на транспорт с 1 по 7 мая 2026 года.

**Действия:**
1. В блоке фильтрации выберите категорию «Транспорт»
2. Установите дату «с»: `2026-05-01`
3. Установите дату «по»: `2026-05-07`
4. Нажмите «Применить фильтр»
5. Нажмите «Подсчитать сумму»

**Результат:** Появляется окно с суммой, например: «Сумма расходов c 2026-05-01 по 2026-05-07: 1250.50 руб»

---

### Пример 3: Просмотр всех расходов за месяц

**Задача:** Посмотреть все расходы за май 2026 года.

**Действия:**
1. В блоке фильтрации выберите категорию «Все»
2. Установите дату «с»: `2026-05-01`
3. Установите дату «по»: `2026-05-31`
4. Нажмите «Применить фильтр»

**Результат:** В таблице отображаются только расходы за май 2026 года.

---

### Пример 4: Ошибка при вводе отрицательной суммы (валидация)

**Действия:**
1. В поле «Сумма» введите: `-100`
2. Заполните остальные поля
3. Нажмите «Добавить расход»

**Результат:** Появляется сообщение об ошибке: «Сумма должна быть положительным числом!». Расход не добавляется.

---

### Пример 5: Удаление расхода

**Действия:**
1. Выделите строку с расходом в таблице (щёлкните по ней)
2. Нажмите кнопку «Удалить выбранный расход»
3. Подтвердите удаление в появившемся окне

**Результат:** Расход исчезает из таблицы и удаляется из файла.
